A program that writes one funny line to `/output/entry.txt`, for the
make.fun competition
[The One-Line Laugh](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f).

Run it with Python 3:

```
python3 main.py
```

It writes the line below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The line is 127 characters, inside the 1 to 200 gate.

## The line

```
My bank charged me to text me that my account is empty, then charged me again for the alert confirming the charge went through.
```
